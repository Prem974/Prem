# AI-Based Personal Finance & Investment Intelligence System

## Project Overview

This project is an AI-based personal finance and investment intelligence system developed using Python, Machine Learning, Data Analytics, and Power BI.

The system analyzes income, expenses, savings, and financial patterns to provide useful financial insights and investment intelligence.

## Technologies Used

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Streamlit, Power BI

## Key Features

- Income and expense analysis
- Savings analysis
- Expense category analysis
- Financial insights
- Investment comparison
- Estimated investment returns
- Interactive Streamlit dashboard
- Power BI dashboard
